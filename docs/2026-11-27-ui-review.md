# Claude Rooms UI/UX 점검표

- 작성 2026-11-27 · 계획 Task 4b · 상태: **5장 결정 확정(2026-11-27, 추천안대로)**. 1~4장의 나머지 제안은 이 문서를 기준으로 Swift 화면에 반영하고, 캡처로 다시 보여 드려 조정한다
- 대상: Electron 화면(`app/renderer/**`)과 캡처 21장(`docs/screens-2026-11-26/`, 창 1100×728). 이 기준으로 SwiftUI(macOS 14+) 화면을 만든다.
- 유지: 토스 같은 분위기, Pretendard, 다크 모드는 시스템 설정. 밀도는 모바일 앱이 아니라 **맥 데스크톱 앱** 기준.
- 분류: **확정** = 사용자가 고치기로 정한 문제(① 버튼이 너무 크다 ② 글이 어색하게 줄바꿈된다). 고치는 방법·숫자는 검토 전까지 모두 **제안**. 그 밖의 항목은 문제부터 **제안**.
- 근거 표기: 캡처는 파일 이름(`03-room-chat`), 코드는 `파일:줄`(`app/renderer/` 기준).

## 1. 요약 — 가장 크게 바뀌는 것

1. **버튼을 4단계로 줄인다**(확정): 지금 56·48·36·20px 네 가지가 제각각 → 큰 36 · 보통 28 · 작은 24 · 텍스트 버튼. 가로 전체 폭 버튼은 로그인 폼에만 남긴다.
2. **어색한 줄바꿈을 없앤다**(확정): 경로·파일 이름·멤버 요약은 한 줄 + 말줄임(…) + 툴팁, 패널 안내글은 한 줄 길이로 줄인다. 줄바꿈이 필요한 곳은 어절 단위로 끊는다(지금은 "함/께", "있/어요"처럼 글자 중간에서 끊김 — `app.css` 에 `word-break: keep-all` 없음).
3. **글자 5단계**(제안): 20 / 16 / 15 / 13 / 12px. 11px 글자를 없애고 패널·버튼 글자는 13px 로 맞춘다.
4. **작은 글자 색 대비 보강**(제안): 라이트 모드의 보조 회색(3.0:1)·성공 초록(2.8:1)·승인 대기 주황(2.1:1)·강조 파랑 글자(3.3~3.7:1)를 4.5:1 안팎으로. 채우기 색은 그대로 두고 **글자용 색**만 따로 둔다.
5. **패널·시트 정보 정리**(제안): 레포 카드 상태를 한 줄로 합치고 버튼 이름을 구체화, 멤버 탭 선택 상자에 이름표, 승인 창은 사람이 읽는 형태(경로 한 줄 + 내용 글자, JSON 은 접기), 시트의 [닫기]가 가장 큰 파란 버튼인 위계를 바로잡는다.

### 2.5 긴 글 처리 규칙 (확정: 어색한 줄바꿈 없앤다 / 방법은 제안)

- **한 줄 + 가운데 말줄임 + 툴팁(전체 경로)**: 파일 경로 전부 — 레포 카드 원격·내 원본·작업 폴더, 함께 읽는 폴더, 도구 실행 줄, 승인 창 경로, 공유 파일 이름. 홈 폴더는 `~` 로 줄인다. SwiftUI `.lineLimit(1)` + `.truncationMode(.middle)` + `.help(전체)`.
- **한 줄 + 끝 말줄임 + 툴팁**: 방 이름, 멤버 연결 요약 값, 코드 카드 머리줄, 모델 차이 안내(설계 결정 31 문구는 그대로).
- **줄바꿈 허용(어절 단위)**: 채팅 말풍선, Claude 답, 실패 사유, 확인 시트 메시지, 미리보기 본문. Electron 은 `word-break: keep-all`, Swift 는 AppKit `NSParagraphStyle.lineBreakStrategy = .hangulWordPriority` 를 쓴다(SwiftUI `Text` 에서 바로 먹는지는 Task 5 에서 확인 필요).
- **줄바꿈 없이 가로 스크롤**: diff, 코드 블록(지금과 같음).
- **설명글은 한 줄**: 패널 안내는 약 20자 안. 더 필요한 설명은 툴팁(ⓘ)으로 뺀다.
