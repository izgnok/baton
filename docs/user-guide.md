# Claude Rooms 사용 가이드

여러 사람이 한 채팅방에서 **같은 Claude 대화(세션)를 이어 쓰는** 맥 앱입니다.
Claude 에게 보낸 요청은 **보낸 사람의 맥에서, 그 사람의 Claude 구독으로** 실행되고, 대화·공유 파일은 방 멤버 모두에게 똑같이 보입니다.

## 1. 준비 (처음 한 번)

| 필요한 것 | 확인·설치 |
|---|---|
| macOS 14 이상 | |
| Command Line Tools (`git`, `swift`) | 터미널에서 `swift --version` 이 나오면 됨. 없으면 `xcode-select --install` |
| Node 24 이상 | `node -v`. 없으면 [nodejs.org](https://nodejs.org) 또는 Homebrew·nvm |
| Claude Code 로그인 | `claude` 가 설치돼 있고 유료 플랜(Pro 이상)으로 로그인돼 있어야 Claude 에게 요청할 수 있음. **방 멤버들과 같은 조직(팀) 계정**이어야 대화를 이어 쓸 수 있음 |
| 서버와 같은 네트워크 | 방을 연 사람의 맥이 서버. 같은 사내망(또는 VPN)에 있어야 접속됨 |

## 2. 설치

```bash
git clone https://github.com/izgnok/claude-rooms.git ~/claude-rooms
```

```bash
cd ~/claude-rooms && npm install && npm run mac
```

`~/Applications/Claude Rooms.app` 이 만들어집니다. Spotlight 에서 "Claude Rooms" 로 열면 됩니다.
`~/claude-rooms` 폴더는 앱이 계속 쓰므로 지우지 마세요.

## 3. 가입하고 방에 들어가기

1. 앱을 열고 **서버 주소**를 넣습니다. 방을 연 사람에게 받은 `http://<IP>:4310` 형태의 주소입니다(그 사람 앱의 설정 ⌘, 에 나옴).
2. **[계정이 없어요? 가입하기]** → 이메일·비밀번호·이름. 이 계정은 Claude Rooms 전용이고 Claude 계정과는 별개입니다.
3. 방 목록에서 **[초대 코드로 참가]** → 받은 초대 코드(멤버 탭 맨 위에 있는 6자리)를 넣습니다.

## 4. 방 화면

```
┌ ← 목록  방 이름     컨텍스트 · 5시간 · 주간 사용량      멤버 n명 ┐
│                                              │ [레포][공유 파일][멤버] │
│  채팅 (사람 = 오른쪽, Claude = 왼쪽)          │                        │
│                                              │                        │
│ [Claude|사람]  모델 · 노력                    │                        │
│ [ 입력창                         ] [보내기]   │                        │
└────────────────────────────────────────────────────────────────┘
```

- **입력창**: 기본은 Claude 에게 보냅니다. **[사람]** 으로 바꾸면 사람끼리만 대화하고 Claude 는 보지 않습니다. `/` 로 시작하면 어느 쪽이든 Claude 에게 갑니다.
  - `Enter` 보내기, `Shift+Enter` 줄바꿈
  - `/` → 명령·내 스킬 자동완성(`/compact` 는 대화를 줄임), `@` → 멤버·공유 파일·레포 파일 자동완성
- **모델·노력**: 방 기본값(방장이 정함)을 쓰고, 입력창 옆에서 나만 바꿀 수 있습니다.
- **승인 창**: Claude 가 파일을 쓰거나 명령을 실행하려 하면 **요청한 사람의 맥에만** 승인 창이 뜹니다. [허용]/[거부].
- **중단·다시 보내기**: 실행 중인 요청 아래 [중단], 중단·실패한 요청은 [다시 보내기].
- **머리줄**
  - **컨텍스트**: 이 방 대화가 얼마나 찼는지. 같은 대화를 이어 쓰므로 멤버 모두 같은 값입니다. 많이 차면 `/compact`.
  - **5시간·주간**: 내 Claude 구독 사용량(사람마다 다름).

## 5. 레포·공유 파일·멤버

- **레포는 채팅으로 정합니다**: "insight 로 NMRS-123 하자"처럼 말하면 Claude 가 기준 브랜치(원격에 있는 브랜치)를 묻고 작업 브랜치 이름을 정해 방에 추가합니다(승인 창). 브랜치를 바꿀 때도 말로 합니다. 레포 탭은 보여 주기만 합니다(`기준 → 작업`, 상태 점).
  - 각자 맥에서 같은 레포(원격 주소가 같은 것)를 자동으로 찾아 쓰고, 없으면 자동으로 받습니다.
  - Claude 는 방 전용 **공유 사본**(`~/.claude-rooms/<방>/repos/…`)에서 일합니다. 누가 시킨 변경이든 끝나면 모든 멤버 맥의 사본에 곧바로 맞춰집니다 — push 없이 이어서 작업. 내 원본 폴더·내 로컬 브랜치는 건드리지 않습니다.
  - 공유 사본 내용은 원본 레포에 `refs/rooms/<방>/<레포>` 로도 보이므로, 내 브랜치로 가져가려면 `git switch -c 내브랜치 refs/rooms/…` 하거나 Claude 에게 시키면 됩니다.
  - 코드를 고치면 실행 뒤 **diff 카드**가 나옵니다. "push 해줘"라고 하면 작업 단위로 나눠 커밋하고 작업 브랜치로 push 합니다. `main`·`develop`·`release/*` 같은 보호 브랜치에는 push 하지 않습니다.
  - **내 맥에서 함께 읽을 폴더**: 레포 바깥의 설정·메모리(상위 폴더의 CLAUDE.md 등)를 Claude 가 읽게 합니다. 내가 보낸 요청에서만 쓰입니다.
- **공유 파일 탭**: 방 메모리(`memory/`)와 Claude 가 만든 결과물(`outputs/`). 내 맥에도 같은 파일이 있고(**[Finder에서 열기]**), 직접 고쳐 저장하면 모두에게 반영됩니다. HTML 은 [브라우저로 열기]로 열면 스크립트까지 동작합니다.
- **멤버 탭**: 초대 코드, 멤버별 연결 상태(레포·읽는 폴더·Claude 로그인), 방 기본 모델, 방장의 "방 설정".

## 6. 업데이트

새 버전이 있으면 화면 위에 **"새 버전이 있어요"** 띠가 뜹니다. **[업데이트]** 를 누르면 받아서 필요하면 앱을 다시 빌드하고 다시 켭니다. 방 목록의 [업데이트 확인] 으로 바로 확인할 수도 있습니다.

## 7. 방을 여는 사람(서버를 켜는 맥)

- 앱 설정(⌘,)에서 **[이 맥에서 서버 실행]** 을 켭니다. 다른 맥에서 접속할 주소가 나오고, 앱을 켤 때마다 서버도 같이 켜집니다. 앱을 완전히 종료(⌘Q)하면 서버도 꺼집니다.
- 방 목록의 **[방 만들기]** → 멤버 탭의 초대 코드를 새 멤버에게 알려 줍니다.

## 8. 문제가 생기면

| 증상 | 해결 |
|---|---|
| "서버와 연결이 끊겼어요" 띠 | 서버 맥의 앱이 켜져 있고 서버 스위치가 켜져 있는지, 같은 네트워크인지 확인 |
| "Claude 로그인이 필요해요" | 터미널에서 `claude` 로그인(또는 방 목록의 [Claude 로그인]) |
| "Node 가 필요해요" 화면 | Node 24 설치 후 앱을 다시 켬 |
| 이전 대화를 이어 가지 못함 | 방 멤버들과 같은 Claude 조직(팀) 계정인지 확인 |
| 앱 로그 | `~/.claude-rooms/core.log`(앱), `~/.claude-rooms/server.log`(서버 맥) |
